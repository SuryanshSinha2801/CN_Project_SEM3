BLACKOUT NETWORK SIMULATOR - PORTABLE WINDOWS BUILD

Requirements:
- 64-bit Windows 10 or Windows 11
- No Python installation
- No Docker installation
- No internet connection after download

How to run:
1. Extract the ZIP file completely.
2. Double-click BLACKOUT_Simulator.exe.
3. Enter a message and select different source and destination nodes.
4. Click Start Custom Message, then Play.

Windows may show a SmartScreen warning because this student-project executable is not
commercially code-signed. Verify the ZIP SHA-256 value with the sender before running it.

The executable contains Python 3.13, project dependencies, the simulation engine, the
Tkinter interface, and the presentation configuration.
